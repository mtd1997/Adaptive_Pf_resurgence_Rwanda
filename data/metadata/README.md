# Metadata and small input files

Small inputs required by the analysis scripts and not available from the
sequence data repository:

- `amplicons.bed` — coordinates of the seven targeted amplicons
- `regions.txt` — drug-resistance regions used for subsetting
- `sample_barcode_mapping.csv` — barcode to sample ID mapping
- `samples_metadata.tsv` — de-identified sample metadata

All metadata here is de-identified: no names, no hospital record numbers,
no dates of birth, no exact collection dates.
