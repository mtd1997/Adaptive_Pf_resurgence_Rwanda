# Adaptive restructuring of *Plasmodium falciparum* populations associated with malaria resurgence in Rwanda

Analysis code for the article of the same name, published in *Nature Communications* (2026).

## Overview

This repository contains the computational workflow used to process Oxford Nanopore amplicon sequencing data, call and annotate variants, and carry out the population genomic and antimalarial resistance analyses described in the manuscript. Each published figure panel is regenerated by a single script, which writes both the figure and the Source Data table behind it, and checks its own output against the values printed in the paper.

## Data availability

The raw sequencing data (FASTQ) and variant files (VCF and gVCF) generated in this study have been deposited in the Gene Expression Omnibus under accession GSE318440 [https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE318440].

Because of their size, sequencing data are not included in this repository.

## Repository structure

```text
config.R                  all file paths, in one place
config.local.R.example    template for the paths specific to your machine
run_all_figures.sh        regenerates every figure and reports what reproduced

scripts/
  00_metadata/            build the de-identified sample roster
  01_preprocessing/       FASTQ concatenation, renaming, QC
  02_alignment/           minimap2 alignment and per-amplicon coverage
  03_variant_calling/     Clair3
  04_filtering/           joint genotyping, filtering, SnpEff annotation
  05_downstream_analysis/ variant tables, drug-resistance markers, selection scan
  06_figures/             one script per published panel

data/
  metadata/               sample roster
  processed/              de-identified mutation table and intermediate tables

results/
  figures/                generated figures
  tables/                 Source Data tables
  logs/                   output of each script, not tracked
```

## Setting the input paths

Several inputs are too large for the repository. Copy the template and fill in
the paths for your machine:

```bash
cp config.local.R.example config.local.R
```

| Variable | What it is | Used by |
| -------- | ---------- | ------- |
| `SELECTION_VCF` | filtered VCF for the selection scan | Figure 5 |
| `SELECTION_ANNOTATION` | SnpEff annotation table | Figure 5 |
| `POPGEN_VCF` | population VCF for the IBS distance matrix | Figure 4 |
| `MALARIA_CASES_FILE` | monthly malaria case counts | Figure S1b |
| `GADM_DIR` | unzipped GADM shapefiles | Figures 1, 3d, S1a |

`config.local.R` is not tracked by git, so the paths set in it stay on the
machine where they were written. A script whose own inputs are present still
runs even when other paths are unset.

## Regenerating the figures

```bash
bash run_all_figures.sh
```

Each script writes its figure to `results/figures/`, its Source Data table to
`results/tables/`, and its full output to `results/logs/`. The run ends with a
table showing, for each script, whether it completed and what its self-check
concluded.

Figure 4d is also checked against the tree used for the published panel, which
is included at `data/processed/kigali_reference_tree.nwk`. The script rebuilds
the tree from the genotypes and compares every patristic distance against the
saved one. To check against a different tree, pass it as an argument:

```bash
bash run_all_figures.sh /path/to/another_tree.nwk
```

Scripts can also be run one at a time:

```bash
Rscript scripts/06_figures/figure03b_k13_category_pies.R
```

## Map boundary data

Figures 1, 3d and Supplementary Figure S1a show Rwandan district boundaries and
the outlines of neighbouring countries, drawn from GADM version 4.1
(`gadm41_RWA_2`, and level 0 for COD, UGA, TZA and BDI). The maps were rendered
by the authors in R using `sf` and `ggplot2`. GADM data are not redistributed
here; download them from https://gadm.org and point `GADM_DIR` at the directory
holding the unzipped files.

## Scope

The scripts cover Figures 1 to 5 and Supplementary Figures S1, S3 and S4.
Figure 6 reports culture-adaptation experiments and structural modelling, and
was not produced by this code.

## Use of AI assistance

Parts of this repository were reorganised with the help of an AI assistant
(Claude, Anthropic). It was used to restructure existing analysis code into
documented, runnable scripts, to add self-checks that compare each script's
output against the values published in the paper, and to write this
documentation. The analyses, the data and their interpretation are the authors'
own; every script was reviewed and run by the authors, and every figure and
Source Data table in this repository was reproduced from the original data
before release. No AI-generated content appears in the published figures.
